02What the tool does

"Tiktok videos" is a backend automation workflow (built in n8n) that:

  • Reads video files that the operator has already produced, from a folder the operator controls;
  • Applies simple, deterministic filtering (for example, filename and duration checks);
  • Publishes the selected video to the operator's own TikTok account using TikTok's official Content Posting API.

No TikTok content is downloaded, scraped, or redistributed. The tool only publishes content the operator already owns.

03Single-user restriction

This tool is built for exactly one TikTok account, controlled by the operator who deployed it. It is not a multi-tenant service, is not distributed to other users, and does not offer sign-up, hosting, or posting on behalf of third parties.

05Compliance with TikTok's own terms

This tool authenticates via TikTok's OAuth 2.0 flow and publishes exclusively through TikTok's Content Posting API, under the scopes granted by the operator's own account. Until the associated developer app has completed TikTok's audit process, all posts are published with SELF_ONLY visibility, meaning they are visible only to the operator.
